# HKcardvault 平台首頁（Home Dashboard）最終整合規格說明書

本文件詳細定義 HKcardvault 電商卡牌交易平台的首頁（Home Dashboard）結構排列、業務邏輯、遊戲化機制以及首席架護師技術防禦部署。整體設計以 **高質感電商體驗** 為核心，融入 **實體中介信任感（對標 SNKRDUNK）** 與 **極致多巴胺尋寶感**。

---

## 🏗️ 全局架構技術棧總覽 (Tech Stack Context)
* **Frontend**: Next.js (全響應式 Mobile-First 設計，支援 PWA 桌面與手機端安裝)
* **Backend / Database**: Supabase (PostgreSQL) 搭配 Edge Functions
* **Media / CDN**: bunny.net (所有卡牌高清原圖、用戶實物圖均經過壓縮並經由 CDN 分發)
* **Payment Gateway**: Stripe Connect (處理兩段式 Escrow 資金託管與自動佣金拆帳)
* **Data Scraper**: Apify + 日本住宅級 Proxy (抓取 Mercari JP 已成交真實行情)

## 🧭 首頁 Section 由上至下黃金排列藍圖

### 🌐 Global Top: 實時成交走馬燈 (Market Pulse Ticker)
* **UI 呈現**：位於全站 Global Header 正下方的極簡動態滾動條。
* **業務邏輯**：滾動顯示全平台最新完成的成交資訊（例：「*玩家*** 剛剛以 $450 成功截胡 摩魯蛾 SAR！*」）。
* **遊戲化/尋寶感**：即時營造「手慢無」的市集熱度與 FOMO（錯失恐懼）心態。
* **🛡️ 首席架構師防禦線**：
    * **禁直連 Realtime**：嚴禁無登入訪客直接連線 Supabase Realtime (WebSockets)，避免連線數爆滿。
    * **快取機制**：由後端 Edge Function 每 30-60 秒將最新 20 筆成交寫入 Redis/記憶體快取，前端 Next.js 透過靜默輪詢（Polling）拉取，實現「零壓力、偽實時」高併發方案。

### 1. 殿堂級首屏：智能搜尋與快速篩選 (Hero & Smart Search)
* **UI 呈現**：高質感背景，視覺中心為巨大的卡牌編號搜尋欄，側邊附帶精緻的 PWA「加到主螢幕」提示按鈕。
* **業務邏輯**：
    * 用戶輸入卡牌編號（如 `SV8a-123`），直接查詢本地 Supabase 快取的 `card_catalog` 資料表，毫秒級彈出帶官方高清原圖的商品預覽。
    * **快速篩選晶片（Quick Filter Chips）**：搜尋欄下方提供橫向滑動的 Pill 按鈕（如：`🔥 人氣女角`、`🐉 噴火龍系列`、`✨ SAR`、`UR`、`SR`、`AR`）。
* **遊戲化/尋寶感**：
    * **全息反光特效（Holographic Foil Effect）**：針對首頁展示的超熱門神卡，運用 CSS 漸變與 WebGL，當用戶傾斜手機或滑鼠 Hover 時，卡面會產生如同真實實體閃卡的全息光影反光，極大化提升視覺衝擊力。

### 2. 信任基礎：鑑定託管流程懶人包 (Trust Booster Banner)
* **UI 呈現**：搜尋欄下方的極簡三步圖文橫幅（How It Works）。
* **業務邏輯**：直接破除用戶對網購假卡的疑慮，具象化教育市場：
    `1. 支付 10-20% 訂金啟動流程 ➔ 2. 官方實體鑑定 4-6 張細節圖確認 ➔ 3. 系統自動扣尾數安全發貨`
* **作用**：建立平台作為專業、鋼鐵般信賴的中介形象。

### 3. 動態再行銷：我的心水情報 (My Following Feed)
* **UI 呈現**：水平滑動的精美商品卡片列（Slider）。
* **業務邏輯**：
    * **已登入狀態**：動態展示該用戶追蹤中的卡牌目前全台最低價現貨，或者其關注的「認證商家」今日最新上架商品。
    * **未登入狀態**：自動展示系統全局熱門推薦，並提示「登入追蹤心水神卡，降價即時通知」。
* **🛡️ 首席架構師防禦線**：
    * **複合索引優化**：此區塊涉及多表 `JOIN` 查詢（用戶 ➔ 追蹤 ➔ 商品最低價）。必須在 Supabase 對 `user_favorites` 表的 `(user_id, listing_id)` 及 `(user_id, merchant_id)` 建立**聯合複合索引（Compound Index）**，否則用戶追蹤量過大時會造成首頁卡頓。

### 4. 🔥【玩家極致尋寶】狙擊雷達 / 破底價專區 (Sniper Radar)
* **UI 呈現**：帶有雷達掃描微動畫的限定商品 Grid 區塊。
* **業務邏輯**：系統演算法自動對比當前賣家的「直接購買價」與由 Apify 抓取的「Mercari JP 近期真實成交平均價（Sold Out Data）」。
* **遊戲化/尋寶感**：
    * 只要定價低於日本市價 10% 以上，卡片即打上醒目的 **`📉 低於日本市價 15%`**、**`⚡ 性價比極高`** 標籤。
    * 引爆重度玩家與投資型收藏家的「執漏（撿漏）」心理，將買卡包裝成一場隨時有寶尋的冒險。
* **🛡️ 首席架構師防禦線**：
    * **異步欄位計算**：嚴禁在首頁載入時實時計算價格差。必須在 Supabase 後端 `listings` 表中預留 `price_delta_percentage` 欄位。當 Apify 更新日本行情或賣家改價時，由後端 Trigger 計算好數值並建立索引，首頁僅進行簡單的 `WHERE price_delta_percentage <= -10` 查詢。

### 5. 核心大招：認證商家・鑑定託管保障區 (Premium Escrow Market)
* **UI 呈現**：大結構、最高質感的商品網格（Grid），對標 SNKRDUNK 核心體驗。
* **業務邏輯**：
    * **嚴格 KYC 門檻**：此區塊商品**僅限**完成 Stripe Connect Onboarding 身份與銀行核實的「商業賣家（Shop 用戶）」上架。
    * **強制實物細節**：賣家必須強制上傳 4-6 張包含卡角、表面、刮痕的實物高清照片。
    * **兩段式金流**：商品預設支援「分段式 Escrow 託管」，買家先付 10-20% 訂金，資金鎖定於 Stripe 託管帳戶，鑑定通過後系統自動扣除餘額。
* **遊戲化/尋寶感**：
    * **🏅 道館主徽章系統**：通過 KYC 且好評率、成交量極高的星級商業賣家，其頭像與商品卡片將會解鎖掛载「**專業道館主**」、「**殿堂收藏家**」等黃金 3D 質感徽章，滿足大賣家的虛榮心，同時給予買家終極信任感。
* **🛡️ 🛡️ 首席架構師防禦線 (RLS 底層防護)**：
    * **資料庫行級安全政策**：在 Supabase 撰寫 RLS 規則，當一筆商品數據 `use_authentication = true`（需要平台鑑定）時，資料庫底層強制校驗發布者的 `auth.users` 屬性中 `account_type = 'merchant'` 且 `kyc_status = 'verified'`。任何黑客嘗試繞過前端 UI 惡意調用 API 上架，都會被 Supabase 底層直接拒絕。

### 6. 資產中樞：個人卡盒與 7 日簽到里程碑 (Portfolio & Daily Rewards)
* **UI 呈現**：精緻的個人化 Dashboard 模組，右側嵌入橫向 7 節點連續簽到進度條。
* **業務邏輯**：
    * **虛擬卡盒身家**：根據系統市價 API，自動加總用戶登錄的持有卡牌，實時算出整套防潮箱收藏的「總身家（Net Worth）」。
    * **每日簽到進度**：例如動態顯示：「*🔥 已連續簽到 5 日！第 7 日即可解鎖『全台免運費券』！*」運費補貼於成交時自動從平台佣金中扣除並補貼給賣家。
* **🛡️ 🛡️ 首席架構師防禦線 (反作弊硬核邏輯)**：
    * **拒絕前端時間**：為防止有心玩家透過修改手機系統時區、或偽造 API Timestamp 來無限刷簽到，Supabase Stored Procedure 必須強制使用資料庫伺服器時間 `timezone('Asia/Hong_Kong', now())`。
    * **聯合約束與行級鎖**：資料庫 `user_check_ins` 表對 `(user_id, check_in_date)` 設為 `UNIQUE` 聯合主鍵。簽到 Procedure 內包裝為 PostgreSQL **原子性事務（Atomic Transaction）**，使用 `FOR UPDATE` 行級鎖，徹底封死 Double Click 或高併發外掛刷券漏洞。

### 7. 執雞情報：最新 C2C 現貨上架 (New Arrivals)
* **UI 呈現**：電商瀑布流，展示全平台私人玩家（C2C）最新發布的散件。
* **業務邏輯**：
    * **UI 按鈕比重調配**：貫徹電商重心的原則，「**直接購買**（以最低現貨價即時成交）」設定為絕對亮眼的主按鈕；而仿股市的「**即時出價**（掛單收購、等待撮合）」則縮小處理為次要按鈕。
* **🛡️ 首席架構師防禦線**：
    * **封面縮略圖優化**：C2C 上架包含大量實物圖。用戶上傳的原始圖片在經由 Edge Function 寫入庫前，必須強制轉為 WebP 格式、壓縮尺寸並上載至 **bunny.net CDN**。首頁列表只抓取第一張封面壓縮圖，滑鼠 Hover 時才異步加載其餘細節，避免首頁 LCP（最大內容渲染）崩潰。
    * **狀態防重鎖定**：一旦某買家點擊「直接購買」並成功支付第一階段訂金，該 Listing 狀態必須在資料庫瞬時變更為 `'escrow_locked'`。此時 RLS 政策會立刻阻止其他用戶對該 `listing_id` 發起支付請求，防止造成 Stripe 重複扣款。

### 8. 大盤風向：日本東京連線市價參考 (Tokyo Market Reference Index)
* **UI 呈現**：乾淨優雅的電商推薦位，移除硬核股市 K 線，每張卡片下方配一條淡淡的迷你趨勢線（Sparkline）。
* **業務邏輯**：基於 Apify 定時（Top 100 熱門每日 4 次、普通每日 1 次）抓取的 Mercari JP 實時**已成交記錄 (Sold Out Data)**，剔除掛單未成交的虛高標價，反映真實日本市場公允價。
* **作用**：為投資型、收藏型玩家提供落單前最終的感性與理性科學參考，進一步提升下單轉化率。
