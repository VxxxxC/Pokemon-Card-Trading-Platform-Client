> 🌐 **語言與字體**：本設計系統使用**繁體中文 (Traditional Chinese)** 作為主要用戶介面語言。主要字體為 **Geist** (UI/Headlines) 和 **Geist Mono** (數據/標籤)，搭配 **Chiron GoRound TC** 作為備選中文字體。所有用戶文本應遵循繁體中文標準，避免簡體或日文混用。

## 1. 視覺主題與氛圍

現代、極簡、數據導向的交易終端，靈感來自**專業金融交易平台**——強調清晰性、精確性與操作效率。氛圍是**沉著、專業、價值為中心**。每個螢幕都以卡牌高清圖像與精確數據為主角，UI 元素優雅地融入專業佈局。想像：Bloomberg 終端與古董展廳的融合。

- **密度**: 6–7 — 高效的資訊密度。卡牌、數據、交易流主導；次要 UI 精簡。
- **變化度**: 4 — 非對稱、單欄或雙欄佈局為主。英雄圖像搭配側邊欄數據面板。
- **動畫**: 5 — 精確的彈簧物理。無永續循環。互動反應迅速、專業、無喧鬧。

## 2. 色彩調色板與角色定義

### 色彩和諧設計理念

平台的色彩主題採用**暗金色深色主題**，呈現**專業、高級、數據驅動**的視覺風格。調色板避免任何藍色調，改用**暖調深色**加**語義性信號色**（綠色=成功、紅色=警告）。

**策略：**
- **背景**: 暗金棕 (#2B1F15) 作為主頁面背景，層級遞進展示深度
- **品牌重點**: 古銅棕 (#8c7355) 用於主要行動按鈕、活躍狀態、品牌強調
- **文字**: 淺米色 (#EDE8E0) 用於主文本；淺灰 (#8A8680) 用於次要文本
- **語義色**: 綠色 (#22C55E) 代表成功/上升；紅色 (#EF4444) 代表警告/下跌

此方法結合**高級品牌感** + **午夜交易終端氛圍** + **語義性清晰度**。

### 中立基礎（暗金色深色系 Dark Mode Only）
- **深棕層** (`#1A1612` / misty-canvas) — App Shell 最底層、Modal 遮罩背景。
- **暗金棕** (`#17130f`) — **主頁面背景**。暗金色核心主題色，平台唯一背景色。
- **棕金卡牌** (`#26211C` / pure-surface) — 卡牌填充、面板、側欄。
- **棕金浮層** (`#2e2925`) — Modal 內容區、下拉選單。
- **棕金懸停層** (`#39342f`) — 列表懸停、選中行。

### 文字（暗色主題）
- **淺米色** (`#eae1da` / off-black) — 主要文字（卡牌名稱、價格、標題）。高可讀性。
- **淺灰文字** (`#d4c4b7` / on-surface-variant) — 次要文字、時間戳、中繼資料。減少視覺競爭。
- **停用文字** (`#50453b` / outline-variant) — 停用狀態、佔位符。

### 品牌重點（溫金棕）
- **溫金棕** (`#d4a574` / warm-gold) — **獨有品牌色**。主要 CTA 按鈕（「購買」、「出價」）、活躍分頁、已選狀態。僅用作**點綴重點**。
- **懸停狀態**: 略亮版本 — 深色模式高亮。

### 語義信號色
- **成功綠** (`#10b981` / bullish-jade) — 交易確認、成功出價、正面通知。
- **警告紅** (`#ef4444` / bearish-crimson) — 只限警告、錯誤、超價提示。

> **設計規則**: 暗金色主題專用。無藍色調。避免飽和度 > 85%。這創造**專業、尊貴、高效**的交易終端環境。

> ⚠️ **禁止藍色 / 禁止淺色模式**：調色板刻意暖調且深色，拒絕冷色調或淺色科技美學。保持語義清晰：綠=成功、紅=警告、棕=品牌。

## 2B. 暗金色主題色彩系統（唯一主題）

### 設計哲學：午夜交易終端美學

深色暗金主題是**唯一的色彩模式**，靈感來自**午夜交易大廳**——深暖金色背景突出品牌古銅棕、卡牌與數據在暗色上發光。整個調色板維持**暖調底色**，拒絕藍色調或冷色調。

**策略：**
- 背景使用**暖調深棕**（暗金色底），不用純中性灰或冷藍黑
- **古銅棕 `#8c7355` 維持完全不變** — 品牌錨點
- 語義色確保深色背景對比
- 文字全用**暖調淺色**

## 3. 字體規則

### 主要字體系統
- **標題 / 標誌**: `Geist` (SemiBold 600 / Bold 700) — 清晰、現代、高對比。用於頁面標題、區段標題。
- **內容 / UI 文字**: `Hanken Grotesk` (Regular 400 / Medium 500) — 所有用戶介面文本、按鈕標籤、卡牌描述。親和力強，溫暖現代感。
- **數字 / 價格**: `JetBrains Mono` (SemiBold 600) — 獨有用於數字價格 (`¥120,000`)、評分 (`PSA 10`、`BGS 9.5`)、序列號。確保數據對齊與精確感。
- **中文備選**: `Chiron GoRound TC` — 當主要字體對特定繁體字符支援不完整時使用。避免混合使用。

### Geist、Hanken Grotesk 與 JetBrains Mono 特性
- **Geist**: 現代無襯線字體，高可讀性、中性、國際化。用於 Headline。
- **Hanken Grotesk**: 親和力較高的無襯線，溫暖現代感。用於 Body 文本。
- **JetBrains Mono**: 優化的等寬字體，適用於數據展示與代碼。確保數值對齊。
- **Google Fonts 免費**: 無授權費用，支援完整拉丁字符與繁體中文基礎字符

### 字體縮放
| 用途 | 字體 | 大小 | 粗細 |
|---|---|---|---|
| 頁面標題 | Geist | 28px | 700 |
| 區段標題 | Geist | 20px | 600 |
| 正文 / 描述 | Hanken Grotesk | 16px | 400 |
| 數據 / 價格 | JetBrains Mono | 18px | 600 |
| 卡牌中繼資料 | Hanken Grotesk | 14px | 400 |
| 標籤 / 徽章 | JetBrains Mono | 13px | 500 |

### 禁用字體
- `Chiron GoRound TC` 作為主字體（改用 `Geist` 或 `Hanken Grotesk`）
- `Inter` — 過度使用、通用。平台級禁用。
- `Roboto`、`system-ui` 作為主字體
- 所有襯線字體（包括 `Garamond`、`Times New Roman`、`Georgia`）
- 除價格和評分外的等寬字體（改用 `JetBrains Mono`）

## 4. Component Stylings

### Buttons
- **Primary (「購入」, 「出價」)**: 古銅棕 fill, 白色標籤, `rounded-lg`. Height `44px` (touch-friendly). Active: gentle `scale(0.98)` spring.
- **Secondary (「検討中」)**: Ghost style. `1px 邊框`, 古銅棕標籤. Same scale-down active state.
- **Tertiary / Text-Only**: No fill, 古銅棕標籤. Lightweight, for secondary actions.
- **Destructive**: 紅色 fill, 白色標籤. Minimal use (only for irreversible actions).
- **BANNED**: 紫色/霓虹光暈、藍色陰影. 改用 `ring-1 ring-brand/30` at most for focus states.
- **Border-radius**: `8px` for rectangular buttons, `full` for pill buttons.

### 卡牌（產品展示焦點）
- 棕金卡牌 (#3A2F1F) 填充、淡邊框 (1px rgba(255,255,255,0.10))、`border-radius: 12px`。
- 陰影: `0 2px 12px rgba(0,0,0,0.50)` — 深暗金背景下的加強陰影。無淺色模式。
- 圖像繁重佈局：卡牌全寬用於英雄照片，標題 + 價格下方。
- 懸停：溫和 `scale(1.02)` + 陰影增加 (`0 4px 24px rgba(0,0,0,0.65)`)。

### 稀有度徽章 (SAR、UR、SR、AR)
- 純 `Geist` 文字、`13px`、無背景。範例: `SAR` 乾淨顯示、最小樣式。
- 可選：`3px` 左邊框重點用古銅棕標示稀有度層級。

### 評分徽章 (PSA 10、BGS 9.5)
- 古銅棕背景: `rgba(140, 115, 85, 0.15)`、`Geist Mono` 文字淺米色 `#EDE8E0`。
- 圓角 `6px`。深色主題下極簡呈現。

### 浮動液體玻璃選項卡欄（底部導航）✨
**設計意圖**: 現代、極簡導航，暗金色主題配置，靈感來自 Apple 的流體玻璃美學。

```
// 手機 / 平板 (< 1024px)
+------------------------------------------+
|                                          |
|    [您的內容在上方捲軸]                    |
|                                          |
+------------------------------------------+
         ┌─────────────────────┐
         │ 🏠  🔍  🎁  👤      │  ← 浮動欄、置中、距底 16px
         └─────────────────────┘
```

**技術規格：**
- **容器**: 固定底部、插圖 `16px` (手機) / `24px` (桌面)、水平置中。
- **寬度**: 手機最大 `280px`、桌面 `320px`。4 個標籤的 Flex 佈局。
- **外觀**: 
  - 背景: `rgba(43, 31, 21, 0.75)` (暗金棕) + `backdrop-filter: blur(20px)`。
  - 邊框: `1px solid rgba(255,255,255,0.10)`。
  - 圓角: `12px` (圓形膠囊形狀)。
  - 陰影: `0 4px 12px rgba(0, 0, 0, 0.50)` (深色環境下的提升)。

**標籤狀態：**
- **活躍標籤**: 
  - 圖示顏色: 古銅棕 (`#8c7355`)
  - 背景: `rgba(140, 115, 85, 0.15)` (古銅棕環境光)
  - 標籤顏色: 淺米色
- **非活躍標籤**: 
  - 圖示顏色: 淺灰 (`#8A8680`)
  - 無背景高亮
  - 點擊反饋: 溫和 `scale(0.95)` 彈簧動畫

**標籤**: 圖示 + 標籤對、`Geist` Regular `11px` 置中於圖示下方。

**動畫**: 標籤轉換使用彈簧物理 `stiffness: 300, damping: 25` 實現順滑顏色/縮放變化。無線性緩動。

**捲軸時**: 
- 捲軸內容時，標籤欄保持固定和可見（從不隱藏）。
- 捲軸時輕微提升增加: `0 6px 16px rgba(0, 0, 0, 0.60)`。

### 保管進度步進器（簡化版）
- 水平時間線：薄 `1px` 連接線、圓形編號節點。
- 步驟: `優惠 → 保管中 → 已發貨 → 檢查中 → 已釋放`
- 已完成: 鮮活綠節點、淡化標籤。
- 活躍: 溫暖金色節點搭配淡微脈衝動畫。
- 待進行: 柔軟邊框輪廓專用。

### 價格顯示
- `Geist Mono` 專用。大價格: `18px`、支援文字: `13px`。
- 價格趨勢指示器: `▲` (綠色) / `▼` (紅色) 搭配差異、語義色彩專用。

### 輸入 / 表單（深色主題）
- 背景: `var(--bg-card)` `#3A2F1F`
- 邊框預設: `rgba(255,255,255,0.12)`
- 聚焦: `ring-2` 使用 `rgba(140, 115, 85, 0.40)` 古銅棕高亮
- 文字: `#EDE8E0` (淺米色)
- 圓角: `8px`

### 賣方入職（簡化版）
- 簡單多步表單，非精靈繁重。
- 頂部進度指示器: `第 1 步，共 3 步`。
- 每步: 單一卡牌搭配單一清晰動作。
- 色彩: 完成時金色進度指示器。

### 載入狀態
- 骨架微光: `rgba(212,165,116,0.08)` 脈衝用於純白背景。
- 微光持續時間: `1.5s` 緩動進出。

### Empty States
- Composed typographic instruction. Example: `まだ取引記録がありません。最初のカードを出品してみましょう。`
- Never plain "No data found" text.

## 5. 版面原則

- **卡牌為中心**: 英雄產品圖像 + 有效的 UI。利用負面空間。
- **最大寬度容器**: `1200px` 置中、`24px` 水平溝槽在桌面。比金融儀表板更多呼吸空間。
- **對稱或單欄優先**: 桌面上單欄或對稱 2 欄卡牌網格。非對稱網格用於特定儀表板佈局。
- **全高部分**: 始終 `min-h-[100dvh]`。永遠不要 `h-screen` (iOS Safari 視窗災難)。
- **間距基礎單位**: `8px`。所有間距值都是 8 的倍數。
- **資訊密度**: 高效但清晰。比 Apple Shop 更多數據，比 Bloomberg 更多呼吸空間。

### 響應式策略
- **手機 (< 768px)**: 單欄折疊。無水平溢出。垂直區段間隙透過 `clamp(3rem, 8vw, 6rem)`。
- **平板 (768px–1023px)**: 2 欄佈局。上方導航或漢堡菜單。
- **桌面 (≥ 1024px)**: 上方水平導航欄或可折疊左側邊欄。完整圖表和表格佈局。
- **觸碰目標**: 所有互動元素最小 `44×44px`。
- **容器填充**: `16px` 手機 / `32px` 桌面。

### 導航模式
- **手機 (< 1024px)**: **浮動液體玻璃選項卡欄** 位於底部置中 — 4 個主標籤 (首頁、搜尋、交易/收件匣、設定檔)。
- **桌面 (≥ 1024px)**: 上方水平導航欄搭配左邊標誌、中央搜尋、右邊用戶設定檔。
- **活躍標籤**: 古銅棕圖示 + 標籤、淡微背景高亮。
- **非活躍標籤**: 淺灰圖示、無高亮。
- **PWA 安裝提示**: 頂部非侵略性橫幅 (非彈窗)。古銅棕行動按鈕。可關閉。

## 6. 動畫與互動

- **彈簧物理預設**: `stiffness: 300, damping: 25` 用於柔軟、精確的互動 (按鈕點擊、標籤轉換)。
- **無線性緩動**: 所有互動狀態變化都使用彈簧或 `cubic-bezier(0.34, 1.56, 0.64, 1)`。避免互動元素的 `ease-in-out` 和 `linear`。
- **觸覺按鈕**: `active:scale-[0.98] active:translate-y-[1px]` 在所有可點擊元素上以實現觸覺反饋。
- **永續微互動**: 最小。活躍標籤節點：僅在古銅棕中淡微脈衝。避免持續動動。
- **卡牌懸停**: 溫和 `scale(1.02)` + 陰影增加。
- **錯開級聯**: 卡牌掛載使用 `staggerChildren: 0.05s` — 瀑布揭示，永遠不要同步彈出。
- **彈窗 / 抽屜進入**: 彈簧縮放 (`scale(0.95) → scale(1.0)`) + `backdrop-blur-sm` 覆蓋層。
- **效能規則**: 僅動畫 `transform` 和 `opacity`。永遠不要動畫 `top`、`left`、`width`、`height` 或 `background-color`。
- **客戶端元件隔離**: 所有彈簧物理和永續動畫必須住在 `'use client'` 元件中。伺服器元件必須無動畫。

## 7. 禁止模式

**排字:**
- `Geist` 預設全平台 — 國際化優先
- `Inter` — 過度使用、通用。平台級禁用。
- 通用襯線: `Georgia`、`Times New Roman`、`Garamond`、`Palatino` — 禁用
- 大標題上的梯度文字
- 身體文字上的重或加粗排字 (700+ 粗細)
- `LABEL // YEAR` 格式化 (例如，`SYSTEM // 2025`) — 懶惰 AI 慣例

**色彩:**
- 純黑 (`#000000`) — 深色主題不用，使用 `深棕層` (`#1A1410`)
- 純白 (`#FFFFFF`) — 深色主題不用，使用 `暗金棕` (`#2B1F15`)
- 淺色背景或淺色模式 — **平台只用暗金色深色主題**，無淺色模式
- 霓虹光暈、藍色氣氛效果、`box-shadow: 0 0 Xpx #color`
- 超過一個品牌重點色彩 (古銅棕是獨有)
- 過飽和重點 (飽和度 > 80%)
- 使用綠色或紅色以外的語義色
- **無藍色調** — 暗金棕主題堅決拒絕冷色調

**佈局:**
- 用於產品展示的相等寬度 3 欄卡牌網格 — 使用單欄或 2 欄
- 重疊元素 — 總是乾淨空間分隔
- `h-screen` 用於全高 — 使用 `min-h-[100dvh]`
- 手機上的水平捲軸
- Flexbox 中的 `calc()` 百分比駭客

**內容 / 資料:**
- `Lorem Ipsum`、`John Doe`、`Acme Corp`、`Nexus` — 任何預留位置名稱
- 虛構中繼資料: `99.98% 正常運作時間`、`124ms 回應`、`18.5k 部署` — 如果真實資料無法取得，請使用 `[中繼資料]` 預留位置
- AI 複製寫作陳詞濫調: `提升`、`無縫`、`釋放`、`下一代`、`授權`
- 填充 UI 文字: `捲軸以探索`、`向下滑動`、彈動雪佛龍、捲軸箭頭
- 破損 Unsplash 連結 — 使用 `picsum.photos` 或本地專案資產
- 用戶介面中的表情符號 (除功能指示器外：✈ 在保管步驟中、✓ 在成功狀態中)
- 虛構儀表板統計 — 無虛構數字

**互動:**
- 互動狀態的 `ease-in-out` 或 `linear` 轉換
- 通用瀏覽器藍色聚焦圈 — 使用 `ring-1 ring-brand/40`
- 自訂滑鼠游標
- 圓形載入旋轉木馬 — 改用骨架微光
- 無錯開的即時列表掛載
- 每個元素上的永續動畫 (保留用於活躍狀態專用)
